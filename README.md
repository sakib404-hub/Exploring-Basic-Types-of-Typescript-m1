# TypeScript Basics Exploration

This repository is created to explore and practice the fundamentals of TypeScript.  
It contains beginner-friendly examples and explanations of core TypeScript concepts.

## 📚 Topics Covered

<table>
<tr>
<td valign="top">

### Primitive Data Types
- string  
- number  
- boolean  
- null  
- undefined  

### Non-Primitive Data Types
- object  
- array  
- tuple  

### Functions
- Function declaration  
- Arrow function  
- Optional parameters  
- Default parameters  
- Function return types  

</td>
<td valign="top">

### Destructuring
- Object destructuring  
- Array destructuring  

### Spread and Rest Operator
- Spread operator  
- Rest parameters  

### Type Alias
- Creating reusable custom types  

### Union & Intersection
- Union types  
- Intersection types  

### Others
- Ternary operator  
- Nullish coalescing  
- Optional chaining  

</td>
</tr>
</table>

## Purpose of This Repository

The main goal of this repository is to strengthen TypeScript fundamentals through simple examples and hands-on practice.

## Getting Started

### Clone the Repository

```bash
git clone 'repository link'
```

### Install Dependencies

```bash
npm install
```

### Run TypeScript Files

```bash
tsc filename.ts
node filename.js
```
